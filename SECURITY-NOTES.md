# Security notes

Prototype; not legal advice; no statement that any law or regulation is satisfied. Commit `v0.1.0`.

## Least privilege by role

All roles are created by the stack (`infra/kiosk_infra/stack.py`); there are no IAM users and no
long-term keys. `<prefix>` is `deploy.resource_prefix`, `<bucket>` the image bucket.

| Role | Actions | Resources |
|---|---|---|
| API function | `dynamodb:GetItem/PutItem/UpdateItem/DeleteItem` | session table |
| | `s3:PutObject`, `s3:GetObject` (presigning) | `<bucket>/s/*` |
| | `s3:ListBucketVersions` (condition `s3:prefix` = `s/*`), `s3:ListBucketMultipartUploads` | `<bucket>` |
| | `s3:DeleteObject`, `s3:DeleteObjectVersion`, `s3:AbortMultipartUpload` | `<bucket>/s/*` |
| | `kms:Decrypt/Encrypt/GenerateDataKey/DescribeKey` | data key |
| | `kms:GenerateMac` | receipt key |
| | `states:StartExecution` / `states:StopExecution` | the expiry state machine / its executions |
| | `lambda:InvokeFunction` | processor function |
| | `logs:CreateLogStream/PutLogEvents` | `/<prefix>/audit` |
| Processor function | `dynamodb:GetItem/UpdateItem`; S3 as above (put/get/purge); data key | as above |
| | `bedrock:ApplyGuardrail` | this guardrail |
| | `bedrock:InvokeModel` (only with `image_model.provider=bedrock`) | in-region: `foundation-model/<id>` in `deploy.region`; cross-region profile: the profile ARN, plus `foundation-model/<id>` in any region **with** `bedrock:InferenceProfileArn` = that profile |
| Expiry function | `dynamodb:GetItem/DeleteItem`; S3 purge actions; data key; `kms:GenerateMac` | as above |
| Authorizer | `secretsmanager:GetSecretValue` (CDK grant: plus `DescribeSecret`), `kms:Decrypt` via the secret's key grant | the kiosk token secret |
| Workflow | `lambda:InvokeFunction` | expiry function (and its versions) |
| | CloudWatch Logs delivery and X-Ray actions | `*` (no resource-level support) |

Resource policies:
- Image bucket: deny `GetObject/GetObjectVersion/PutObject` for every principal except the API and
  processor roles; deny `GetObject` with `s3:signatureAge` above the link lifetime; deny non-SigV4;
  deny non-TLS (CDK `enforceSSL`, minimum TLS 1.2).
- Data key: the account root (CDK default) and CloudWatch Logs for log groups named `/<prefix>/*`
  only (`kms:EncryptionContext:aws:logs:arn`).

## Trust policies

| Role | Principal | Conditions |
|---|---|---|
| Workflow role | `states.amazonaws.com` | `aws:SourceAccount` = this account **and** `aws:SourceArn` ArnLike the state machine ARN (built from its fixed name, no circular reference), as recommended in the [Step Functions confused-deputy guidance](https://docs.aws.amazon.com/step-functions/latest/dg/procedure-create-iam-role.html#prevent-cross-service-confused-deputy) |
| Lambda execution roles | `lambda.amazonaws.com` | none: the [Lambda execution role guide](https://docs.aws.amazon.com/lambda/latest/dg/lambda-intro-execution-role.html) defines the trust policy with the service principal only and documents no confused-deputy condition keys for it; each role is bound to its function by `iam:PassRole` at deploy time |
| CDK handler roles (auto-delete objects, page deployment) | `lambda.amazonaws.com` | generated by CDK |

## cdk-nag acknowledgements

All AwsSolutions findings are either fixed or acknowledged on the construct that triggers them,
with finding ids built from configuration (prefix, model id, link lifetime), so other parameter
files still synthesise cleanly (`tests/test_infra.py::test_other_prefix_still_clean`).

| Rule | Construct | Reason |
|---|---|---|
| S1 | image bucket | server access logs would record the IP address of every phone that downloads a result; data minimisation wins in the prototype; object-level audit is the application audit log (CloudTrail data events optional, handover) |
| S1 | site bucket | static page assets only; logs would only add viewer IPs |
| DDB3 | session table | point-in-time recovery would keep deleted session records restorable, contradicting deletion on request; the table holds no images |
| SMG4 | kiosk token secret | rotation is a production hardening item; it is a device token, not a user credential |
| CFR1 | distribution | geo restriction is a parameter (`frontend.geo_allowlist`), empty in the sandbox |
| CFR2 | distribution | page assets only; WAF for CloudFront is a hardening item |
| CFR3 | distribution | viewer logs contain IP addresses |
| CFR4 | distribution | default CloudFront certificate (no custom domain); custom domain with a modern TLS policy is a hardening item |
| IAM5 | API, processor, expiry, authorizer default policies | `<bucket>/s/*`: session object keys are created at run time; `execution:<prefix>-session-expiry:*`: execution names per session; (cross-region profile only) `foundation-model/<id>` in `*` regions, limited by `bedrock:InferenceProfileArn` |
| IAM5 | workflow default policy | `<expiry function ARN>:*` added by the LambdaInvoke task; `*` for logs delivery and X-Ray actions without resource-level permissions |
| IAM4, IAM5, L1 | CDK BucketDeployment handler | generated by CDK (managed basic execution policy, grants on the site bucket and CDK asset objects, runtime chosen by CDK); runs only during deployment |

Fixed rather than acknowledged: APIG1 (access logging on the HTTP API stage), APIG4 (Lambda
authorizer on every route), L1 for the project's own functions (Python 3.14), SF1/SF2 (workflow
logging at ALL without execution data, X-Ray), S10 (TLS), KMS5 (rotation on the symmetric key),
IAM4 for the project's roles (no managed policies).

## Known risks and limits

- The kiosk device token is a shared secret placed on each kiosk; anyone who extracts it can call
  the API within the stage throttle. Production: per-device credentials (for example mTLS on a
  custom domain, or IAM credentials per device) and AWS WAF in front (HTTP APIs do not integrate
  with WAF; use a REST API or CloudFront + WAF).
- Presigned links are bearer links until they expire.
- API Gateway throttling is best effort.
- Content filters produce false positives and negatives (VERIFICATION.md records one false positive).
- With `allow_cross_region_inference=true`, images may be processed in another region of the
  profile's geography.
- CloudFront is a global service; with `frontend.enabled=false` the page is served by the kiosk.
- The CDK auto-delete custom resource (sandbox `removal_policy=destroy`) creates a log group named
  `/aws/lambda/<stack>-CustomS3AutoDeleteObjects...` without retention; `make destroy` deletes it.
- Lambda functions are not in a VPC; they call AWS service endpoints over TLS.
