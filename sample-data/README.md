# Sample data

Synthetic only. No photographs, no people, no real data. Not legal advice.

- `manifest.json` (committed): every sample image, what it tests and the expected outcome.
- `images/` (git-ignored): generated by `make samples` (`scripts/gen_samples.py`, Pillow shapes,
  colour blocks and text). CI generates them before the tests.
- `audit-log-sample.jsonl` (committed): audit events of one offline demo run
  (`scripts/demo_local.py --write-audit-sample`). Every line is checked against the audit
  allowlist by `tests/test_audit_and_logs.py`.

The magenta and cyan 16x16 patches in the corner of two samples are markers for the offline mock
moderation only (`src/kiosk/local.py`). The mock is not a classifier.
